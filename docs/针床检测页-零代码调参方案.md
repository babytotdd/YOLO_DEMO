## 一、结论先行

1. 能识别边缘，但不能用"最大连通域外沿"。板面与背景的分离余量足够（饱和 S 差 3~5 倍），
   但掩膜一定是"多孔"的（丝印、器件、反光被挖空），最大连通域在真实 OK 帧之间的外沿抖动
   就有 20~84 px，比 NG 信号还大。改用"掩膜外溢像素数"就稳了。
2. ROI 只需一个，不需要多定位销。定位销是透明亚克力，与底板几乎零对比度，检测销子本身不可靠；
   4 个黑色导向块固定不动，可以作为天然基准，但不用单独框。
3. 最简单直接的办法：判定方式切到「形状匹配（旧）」，把"金样板外扩 6.8 mm"当唯一硬门限，
   其余容差全部放宽。实测 OK 帧外溢 71 px、NG 帧 7043~24694 px，门限 451 px，差 15~55 倍。

## 二、为什么现在"框选效果不好"

| 机制性问题 | 说明 |
|---|---|
| 单帧标定阈值会漂 | EstimateSegment 用金样板一帧的 HSV 分位当区间，光照/反光一变就失配；本机现有配方 sMax=165 更把板整体排除了（板面 S≈174） |
| 只用一个最大外轮廓 | 丝印/高光把掩膜挖成 25~31 个碎块，最大连通域换块，x/y 1%/99% 分位四条边一起跳 20~84 px |
| 安全区模式是单向的 | 只能抓"产品越出安全区"，抓不到"产品整体移开/变小"（余量只会变大）。图4/图5 属于整体平移，zone 模式原理上抓不住 |
| 相机是斜视 | 世界矩形在图上呈梯形（近端 1640px、远端 1390px），矩形安全区必然近端切角、远端留白 |

## 四、零代码操作步骤（当前配方已按此写好）

0. 先关闭正在运行的 YoloFool（否则界面里的旧配方会把文件覆盖回去），再打开。
1. 【调试模式】→【分割参数】页：
   - 色相 H 60 ~ 130，饱和 S 90 ~ 255，亮度 V 40 ~ 255
   - 形态核 5（奇数），勾选差分，差分阈值 18
   - 点【应用并保存】（必做：会重画 golden_mask.png，7.4 万 px 变成约 22.6 万 px）
2. 【阈值】页确认：
   - 判定方式 = 形状匹配（旧）
   - 位置允许偏移 15 mm；角度允许偏转 5°
   - 确认帧数 1（现场稳定后改 2）
   - 点【高级参数】展开：X/Y 公差 15/15、IoU 下限 0.35、安全区外扩 6.8 mm、
     面积比 0.60/1.40、高光比例上限 0.15、轮廓分下限 0.30、充实度允许下降 0.30
   - 点【保存阈值】
3. 现场验证：
   - 放一片 OK 板：应判 OK，日志里"越界"约 0.0x mm 量级
   - 故意把板向远端推 1~2 cm 或转 2°：应判 NG（OUT_OF_ZONE）

## 五、风险与调节

| 现象 | 处理 |
|---|---|
| OK 板偶发误判 NG | 安全区外扩 6.8 改 7.9 mm（35 px） |
| 轻微没到位判 OK | 安全区外扩 6.8 改 5.6 mm（25 px），或看日志溢出量分布定中间值 |
| 提示图像质量不合格 | 高光比例上限 0.15 改 0.25；本机 NG1 实测高光 7.9%，已贴近默认 8% |
| 提示多目标/找不到产品 | 形态核 5 改 3；或检查 ROI 是否被拖动 |

顶视相机对 Z 向（翘起/浮高）无分辨力。本轮已确认图4/图5 为平面平移；
若要防翘起，需加侧视相机、激光测距或 4 角微动开关（硬件方案）。

## 六、后续（非本轮）
